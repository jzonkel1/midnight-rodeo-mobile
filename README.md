# Midnight Rodeo mobile demo

A mobile-first redesign with Western display typography, neon colors, a silent background video, event flyers, VIP information, hours, directions, and click-to-call actions.

Open `index.html` or serve this directory with any static web server. No package installation or build is required. All paths work on GitHub Pages, including under a project subdirectory.

The inquiry form opens the visitor's email app with a prepared message. It does not store inquiries or claim to submit them to a backend.

See [ASSETS.md](ASSETS.md) for the stock-video license, official venue reels, and image notes. Business details and specials come from the original demo and supplied venue flyers; confirm them with the manager before adopting this as the official site.

Validation: phone, tablet, and desktop layouts; mobile menu; event flyer dialog; VIP inquiry selection; silent video playback and pause; asset links; JavaScript syntax; venue-time handling across midnight and daylight saving changes.
